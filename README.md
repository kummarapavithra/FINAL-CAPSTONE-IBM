Travel Planner Web Application 

->Project Overview

The Travel Planner Web Application is designed to help users plan their trips.
Users can search destinations, create travel plans, and manage their itineraries in one place.

This project is tested using the Software Testing Life Cycle (STLC), and this document represents Phase 1: Requirement Analysis & Test Planning.


Objective

-Understand the application features
-Identify what needs to be tested
-Plan the testing approach
-Identify possible risks early


->Functional Requirements
The system should allow users to:
-Register and log in
-Search for travel destinations
-Create travel itineraries
-Add places or activities
-Edit or delete plans
-Save trips for future use

->Non-Functional Requirements

-Fast and responsive performance
-User-friendly interface
-Secure user data
-Works on modern browsers (Chrome, Edge)
-Reliable without crashes
-UI testing (buttons, forms, layout)
-Testing travel plan creation
-Negative testing (invalid inputs)
-Usability testing

->Automation Testing

-End-to-end workflow testing
-Regression testing
-Data-driven testing

->API Testing (if applicable)

-Validate data fetching
-Check response accuracy

->Database Testing

-Verify saved travel plans
-Ensure data consistency


->Risks

-Incorrect travel plan creation
-Data not saved properly
-Performance issues
-Poor user experience

->Entry Criteria

-Requirements are defined
-Test environment is ready
-Test data is available

-> Exit Criteria

-All test cases executed
-Critical bugs fixed
-Test report generated

->Conclusion
This phase ensures that all requirements are clearly understood and a proper testing plan is prepared before moving to the next stages of STLC.
